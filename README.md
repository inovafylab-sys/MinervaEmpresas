# Minerva Empresa

Documentação de contexto e desenvolvimento do Produto Minerva Empresa: sistemas Médico e Paciente, Copilot da equipe, Cérebro, dados e Workspace.

## Documentos — ordem de leitura

1. **[Contexto da Minerva para o Replit](docs/produto/00-contexto-minerva-para-replit.md)** — propósito, usuários, jornadas, conceitos e decisões que orientam a interface. Comece por este documento.
2. **[Workspace: páginas e subpáginas](docs/produto/workspace-especificacao-funcional.md)** — conteúdo, ações, navegação, fichas contextuais, permissões e apresentação por perfil.
3. **[Contexto, jornadas e contratos de execução](docs/produto/minerva-contexto-e-jornadas.md)** — arquitetura CEBD/W, etapas, gatilhos, consolidação, dados e construção modular.

Os documentos distinguem decisões confirmadas, propostas técnicas e pendências. São uma base de desenvolvimento; não representam uma aplicação ou integrações já implementadas.

## Divisão de trabalho

- **Replit:** frontend e Workspace (W).
- **Codex:** Comunicação, Execução, Cérebro e Dados (CEBD), inicialmente com n8n, Obsidian e PostgreSQL.

O frontend e o backend devem compartilhar contratos, sem duplicar regras ou apresentar dados simulados como execução real.

## Como baixar

No GitHub, use **Code → Download ZIP** para baixar este repositório com os três documentos. Para um arquivo individual, abra o documento e use **Download raw file** quando disponível.

## Como começar no Replit

Conecte este repositório e peça ao agente para ler os três documentos na ordem acima antes de propor ou implementar a interface. As referências visuais citadas precisam ser fornecidas separadamente; suas imagens não estão incluídas neste repositório.
